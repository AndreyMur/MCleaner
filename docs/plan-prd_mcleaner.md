# Plan: MCleaner Desktop Application

**PRD:** prd_mcleaner
**Дата:** 2026-09-05

## Фазы реализации

### Фаза 1: Tracer Bullet — Backend APT (Linux)

**Цель:** Минимальный рабочий бэкенд для управления пакетами через APT
**Затрагивает:** backend
**Задачи:**
- [ ] Интеграция с APT: получение списка установленных пакетов
- [ ] Очистка кэша APT (`apt clean`)
- [ ] Dry-run режим для операций удаления
- [ ] Blacklist критических системных пакетов
- [ ] Unit-тесты для APT-адаптера

**Когда готова:** Команды `apt list`, `apt clean`, симуляция удаления работают из командной строки

---

### Фаза 2: Tracer Bullet — Frontend Shell (Dashboard)

**Цель:** Базовый UI-каркас с дашбордом, отображающим данные от бэкенда
**Затрагивает:** frontend
**Задачи:**
- [ ] Настройка Tauri + React/Vue/Svelte
- [ ] Базовый лейаут с навигацией
- [ ] Дашборд: отображение занятого места кэшем и счетчика пакетов
- [ ] Подключение к бэкенду APT через Tauri commands
- [ ] E2E-тесты дашборда

**Когда готова:** Приложение запускается, показывает реальные данные APT

---

### Фаза 5: Frontend — Package Manager Module

**Цель:** Полноценный интерфейс управления пакетами
**Затрагивает:** frontend
**Задачи:**
- [ ] Табличный/карточный список пакетов с поиском и фильтрами
- [ ] Удаление пакета с подтверждением (модальное окно)
- [ ] Автоматический запуск autoremove после удаления
- [ ] Отображение зависимостей и размера
- [ ] E2E-тесты модуля Package Manager

**Когда готова:** Пользователь может просматривать, искать и удалять пакеты через UI

---

### Фаза 6: Frontend — Cleaner Module
